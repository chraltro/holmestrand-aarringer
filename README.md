# Holmestrands årringer

Holmestrand og Rove vokser frem bygning for bygning, fra kirken i 1674 til det nye rådhuset i 2026, med jernbaner og veier som kommer og går.

Åpne siden og trykk på en bygning for å se året og hvor det kommer fra. «Om dataene og kildene» i menyen forklarer kildene.
